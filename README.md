# 🚦 Sistema Predictivo de Tráfico Vehicular — Cajamarca 2026

Aplicación web interactiva basada en **Machine Learning (XGBoost)** para la estimación del flujo vehicular y soporte a la semaforización adaptativa en las arterias estructurantes de la ciudad de Cajamarca.

## 📌 Corredores Viales Incluidos
1. **Av. Hoyos Rubio** (Intersección Vía de Evitamiento Norte)
2. **Av. Atahualpa** (Intersección Vía de Evitamiento Sur)
3. **Av. Los Héroes**

## 🚀 Despliegue en Streamlit Cloud (24/7 Gratis)
1. Sube este repositorio a tu cuenta de **GitHub**.
2. Entra en [share.streamlit.io](https://share.streamlit.io/).
3. Inicia sesión con GitHub.
4. Haz clic en **"New app"**, selecciona este repositorio, rama `main`, archivo principal `app.py`.
5. ¡Listo! Obtendrás una URL pública activa las 24 horas del día.

## 💻 Ejecución Local
Para probar la aplicación en tu computadora:

```bash
pip install -r requirements.txt
streamlit run app.py
```
